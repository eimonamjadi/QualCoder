AI-assisted qualitative coding, with receipts.

QualCoder codes interview transcripts against your codebook. Every code the AI applies comes with the exact quote, a justification, and links to the codebook entries, examples and prompts it relied on. You accept, reject or fix each one, and your corrections steer the next run.

How it works

A deductive coding workflow where the model has to show its work, and the app checks it.

1 · Codebook

Define codes in your own words

Definition, include-when, exclude-when, and example quotes, including negative examples of what a code is not.

2 · Documents

Upload transcripts

.txt, .md, .docx or .pdf. Text is split into passages at blank lines and speaker labels like P07:, with character offsets kept.

3 · Prompts

Steer the coder

Write instructions such as “don't code interviewer turns”. Each is shown to the model as PROMPT:n so it can cite which one it followed.

4 · AI coding

Structured, cited output

For each passage the app retrieves relevant codes, examples and past corrections, and asks for code, verbatim quote, justification, cited refs and confidence.

5 · Checks

Flags, not trust

Quotes that aren't verbatim and refs the model was never shown are flagged. The exact prompt and raw reply of every run are saved and viewable.

6 · Review & learn

Corrections become training

Rejections become negative examples, fixes become positive ones, and retrieval feeds them into later prompts. Undo removes them again.

Bring your own model

All providers fill the same JSON schema, so the rest of the app doesn't care which one ran.

ProviderNeedsNotes
claude (default)ANTHROPIC_API_KEYClaude Opus 5.5 with structured outputs; codebook in a cached system block
openaiOPENAI_API_KEY, QUALCODE_OPENAI_MODELChat Completions with a strict JSON schema
ollamaOllama running locallyOpen-weight model; transcripts stay on your machine
mockNothingOffline keyword matcher for demos and tests. Not a model.

Run it locally

Python 3.10 or newer. One install, one command.

git clone https://github.com/eimonamjadi/QualCoder.git && cd QualCoder
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...    # or choose mock / ollama in Settings
uvicorn qualcode.main:app --reload

Open http://127.0.0.1:8000, go to Documents, click Load sample codebook + transcript, then Review → Code all passages.

Exports

coded_segments.csv with every applied code, quote, justification, refs, flags and review status; training_data.jsonl of reviewed passages in chat format, a starting point for fine-tuning an open model later.

Data and privacy

Everything is stored locally in SQLite. Passage text is sent only to the provider you choose. Use ollama if transcripts must not leave your machine, and check your IRB and data agreements before sending participant data to a cloud API.

Status

A working prototype. Not built yet: inter-rater reliability, sub-passage span coding, multiple users, embedding retrieval, and fine-tuning from corrections.
